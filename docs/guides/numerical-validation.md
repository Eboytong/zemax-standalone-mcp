# 光学条件与原生诊断验收

适用环境：本机 Windows、OpticStudio 2024 R2（24.2.0 / build 240529 / PremiumEdition）和项目 Python 3.14。

## 执行方法

在项目目录中执行：

```powershell
$env:PYTHONUTF8='1'
.venv/Scripts/python.exe -B -m pytest tests/test_pupil_coupling_live.py --run-zemax -q -p no:cacheprovider
```

按所需模型选择对应测试文件；上例仅执行矩形瞳和小角度耦合。普通测试不创建OpticStudio实例。原生测试通过工作副本执行；每个stdio场景保存calls.json、checks.json，求解矩阵另存matrix.json。GUI、普通测试、原生调用和光学数值各自评定。诊断仅在有新线索时单独运行，入口见诊断程序（历史参考）。

## 求解矩阵

覆盖 Standard、EvenAspheric、OddAsphere、Toroidal、Biconic、Paraxial、CoordinateBreak、GridSag、GridPhase；枚举活动基础单元格与 parameter_1..20，以及九类公开 solve。

矩阵分别记录通过、原生列表不支持、不适用、原生拒绝及待补数值参考。Fixed、Variable、SurfacePickup 检查状态、数值和保存重载。其余 solve 的既有数值参考见[能力说明](capabilities.md)；49个专项组合已对应46个数值通过和3个原生未采用，完整范围见[求解支持表](solve-support.md)。

原生列表声称支持某模式，并不保证当前单元格实际采用。写入后回读 Solve；未采用请求模式时返回错误并保留检查点。PARTIAL_UPDATE 表示原生修改可能已经发生。

## 非零 Cooke 波前

Cooke 14°、20°视场采用非零像差，以逐光线 CurrentAndChief OPD 独立核对 remove_tilt=false、use_exit_pupil=false 的波前网格。全部六档采样（32、64、128、256、512、1024）各检查三个光瞳点，共36项，采用 rtol=1e-7、atol=1e-8 waves。

本机 WavefrontMap 的原生 Min/Dx 元数据使用端点跨度；实际光线采样具有保护边界，其瞳坐标为 (index-floor(size/2))/(floor(size/2)-1)。结果据此返回 min_x/min_y/dx/dy，并在 native_axes 中保留原生值。该定义仅用于 use_exit_pupil=false 的 WavefrontMap。use_exit_pupil=true 保留原生轴，不采用入瞳坐标修正；其他分析网格保持各自定义。图中保护采样和无效值保留。


## 波前公开选项

remove_tilt/use_exit_pupil 的四种组合均通过真实 stdio 调用；覆盖六档采样和14°视场，64×64另覆盖20°视场。use_exit_pupil=true 时省略两个选项以验证公开默认值；64×64另核对显式 true/true 与默认请求的数值一致性。

use_exit_pupil=false：以归一化入瞳光线独立核对非零 OPD，去倾斜前后差值按仿射倾斜项核对。use_exit_pupil=true：核对保留原生轴、主光线 OPD、去倾斜前后的仿射关系及默认请求；未将出瞳图坐标直接作为入瞳追迹输入。

手册§3.2.3.2、L17779说明Use Exit Pupil Shape会按像点所见出瞳形状改变图形。结果的pupil_frame区分normalized circular entrance pupil与apparent exit pupil shape；coordinate_validation明确实际核查范围。规则圆形轴对称模型的主波长显示映射已有双方向F-number与逐光线OPD依据，定义和误差含义见[规则波前映射](model-adaptation.md#规则波前显示坐标映射)。非主波长和其他模型仍待验；当前映射不重建真实出瞳面。

## 生命周期诊断

Python 与独立 C# 各运行五种场景、每场景三次。分别保存 stdout、stderr、带时间戳的输出到达记录，以及立即刷新到独立 JSONL 文件的生命周期事件。

DLL 加载、初始化、连接对象场景未出现 FRU；创建应用及访问主系统后关闭的场景，两种语言均出现一次。30 次进程均退出0。现象并非 Python 桥接独有；输出到达时间不能作为原生内部产生时间，内部根因仍未确认。

## 矩形瞳与倾斜耦合的适用范围

矩形瞳使用轴上单色抛物面反射镜，矩形角点位于直径10 mm的圆形光阑边界。均匀矩形瞳的非相干 MTF 为 max(0, 1-f*λ*focal_length/D)，D 为对应方向的全宽；λ=0.00055 mm，焦距100 mm。子午方向取 Y，弧矢方向取 X，按原生系列标签对应，交换宽度后重复检查。该参考使用标量近轴近似，显式容差包括有限采样误差。

倾斜耦合的两个高斯束腰位于同一平面，幅度为 exp(-x²/wx²-y²/wy²)，w 是1/e幅度半径。各轴束腰为 a、b，角度引起的相位梯度为 q 时，接收效率为各轴 [2ab/(a²+b²)]*exp[-q²a²b²/(2(a²+b²))] 的乘积。绕 Y 倾斜对应 qx=k*sin(tilt_y)，绕 X 倾斜对应 qy=k*sin(tilt_x)，k=2π/λ。验收限于记录的小角度、无横向偏心和零传播距离；大角度的投影、不同端面位置、复杂相位及偏振模式仍需各自参考。

执行方式：

```powershell
$env:PYTHONUTF8='1'
.venv/Scripts/python.exe -B -m pytest tests/test_pupil_coupling_live.py --run-zemax -q -s
```

两个测试均通过真实 stdio 调用，读取实际孔径、模式、采样及倾角，并保存基线、请求、响应、参考公式和逐项检查。可独立运行 test_rectangular_pupil_mtf_native 或 test_tilted_gaussian_coupling_native。请求示例见 [pupil_coupling_requests.json](../examples/pupil_coupling_requests.json)，逐项依据见专项验收（历史参考）。示例中的计算调用返回任务编号，使用 get_task_status 等待完成后再读取 get_task_result。

## 非零复瞳与偏振耦合参考

受控GridPhase分别施加0.2 waves的球差、彗差、像散和离焦多项式。在轴上抛物面反射模型中，以独立复瞳自相关积分核对10/25/50 cycles/mm的子午和弧矢MTF，绝对容差0.02。球差、像散和离焦另以二维复振幅积分核对PSF样点及20μm内能量比例，容差0.025。彗差PSF中心线采用带符号傅里叶核，局部像面方向以独立逐光线光扇确认；不通过翻转图像选取更小误差。四种像差的入瞳波前、Fringe前16项多项式重建和主光线参考光扇分别核对。

POP偏振耦合按手册分别归一化X/Y重叠积分，再按入射分量功率加权。128×64、非对称光束、空间相位和椭圆偏振的文件模型使用独立离散积分，效率绝对容差0.0005。接收Jones向量正交时，该定义仍可能给出1；一次归一化矢量内积则可为0，两者物理量定义须区分。

非序列共偏振平面波模型使用已知方向和起点相位，条纹周期为波长除以两束光线X方向余弦之差。不等功率0.25/0.75 W、32像素、每周期4样本的模型核对逐像素Power及拟合可见度。Rectangle的默认标量结果不自动合成矢量场，局部偏振分量须结合参数16选择。

## 非圆瞳的PSF与能量

矩形半宽4×3mm、环形内外半径1.5/5mm，均使用轴上100mm焦距抛物面镜、0.55μm波长。独立二维瞳积分采用256、512两档参考采样；先检查加密误差小于0.005，再以0.025绝对容差核对PSF样点及10/20μm的衍射圈入能量。能量分母采用Parseval全平面积分 `(λf)²∫|P|²dA`，不以有限图片窗口内能量冒充总能量。像面步长0.5μm。

## 荧光能量与发射谱

`_sample_3.ZES`的权重按光子谱解释，Q=1的输出能量为`Iabsorbed·λin/λout`。稀薄模型使用0.47μm、100000条光线、seed42、1mm球形探测器；源和探测器均在同一N-BK7体内，避免玻璃出口和全反射选择效应。由摩尔消光系数、粒子数密度及阿伏伽德罗常数计算吸收概率，再积分Stokes损耗。总功率、转换光子数采用六标准误差及2×10⁻⁵的插值/微弱再吸收预算。

`WlUM`是光线头波长；`Wn`过滤源波长。`X_WAVERANGE(3,a,b)`按手册检查探测器处波长，a/b以微米表示，双端包含。本机该稀薄模型的402条转换光线在原生过滤中表现为约0.55μm；两个相邻闭区间525–550和550–575nm均选中全部402条，其他25nm区间为空，与独立逐光线波长不符。直接属性式与官方重载、两种完整保存格式均复现，当前波长表变化未使细分正确。总能量通过、原生路径一致和分波段数值失败分别记录；内部原因未确认。逐光线集合判据及范围见[原生波长区间过滤](nonsequential-validation.md#原生波长区间过滤)。

在均匀N-BK7、毫米单位且光程非零的受控记录中，使用`λum=1000·OpticalPathLU/OpticalPathW`还原每段波长。以独立Sellmeier系数核对逐段折射率，再检查逐光子的Stokes能量；402条转换光线的折射率最大差为6.03×10⁻⁸。由这些波长分箱，光子谱与功率谱均符合预设六标准误差和积分预算。该参考不使用强度反推波长，不覆盖零光程、GRIN或全部ZRD格式，也不表示X_WAVERANGE细分过滤已修复。

## 有限相干长度与多事件散射

均匀波长带宽取`Δλ=λ²/Lcoh`，相干曲线为波数积分后复振幅的平方。有限N条光线的期望为`1/N+(1−1/N)|μ|²`，方差由相位二阶、四阶矩独立计算；七个光程差、N=10000、seed42采用六标准差及积分加密预算。结论限定于记录的均匀带宽。

AngleScattering的近前向模型取6mm轴向长度、2mm平均自由程、10000条光线、seed42。以Poisson均值3核对事件次数，以截尾指数分布核对首次自由程CDF。ZRD分块读取保留逐光线归属。有限大角随机游走、多介质路径及完整角分布仍需独立参考；未探测功率保持未分类。

## Ince及空间Jones场传播

Ince-Gaussian DLL的p=m=2、偶/奇模式、w0=0.1mm、f0=0.05/0.1mm，以独立Ince本征多项式核对全腰面强度和带符号复场比值；公共全局相位不影响相对复场。强度绝对容差0.001、功率及复场样点0.0005；其他阶次和传播相位按独立任务处理。

空间Jones文件场包含椭圆偏振、空间变化偏振角及二次相位，分量重叠各自归一化。10mm传播以独立Fresnel积分核对辐照度，接收模式在终止面显式定义0.025mm偏移和±0.02°倾斜，效率与归一化强度预算均为0.005。手册L20495、L20606规定POP正相位表示波前向+Z前移，因此存储场对应常规`exp(+ikz)`推导中的共轭场：`native_out=conj(Fresnel(conj(native_in)))`。正线性相位梯度的物理质心为`−zλ·gradient/(2π)`，独立检查符号。

接收倾斜是线性相位设置，不自动执行真实端面倾斜、投影Jacobian或远端横移。手册L21138–21140要求在终止面积分并明确模式位置；L21356说明POP慢束近似。大角度与真实斜端面不据此判为通过。

## 非对称热间隔与公差样本

两个间隔分别使用100/50ppm/°C、20/50°C和带符号Ry(5°)、Rx(−3°)。曲面前端/平面后端的接触厚度关系为`L(T)=[L0−sag(r)]s+sag(rs)`，s为膨胀比例。逐配置核对两段厚度、九个旋转元素、三分量全局端点及保存重载。任意接触约束和热应力需要其他物理模型。

STAT分别作用于后续TTHI，128个保存镜头读取实际厚度；Uniform二阶矩1/3，截断2σ Normal按截断积分，Parabolic密度与x²成正比、二阶矩3/5。六标准误差在执行前固定。COMP最小/最大值是标称厚度的相对偏移，生成绝对目标后成为软约束；8个OptimizeAll_DLS、5循环样本核对目标、触边距离及越界量。保留所有样本，不把软约束当作硬范围裁剪。

## 有限模型验收与复现

扩展模型的固定输入和容差见[有限验收清单](../tests/reference_data/finite-acceptance.json)，逐项结果见有限模型验收（历史参考）。清单限定 Cooke 三视场、三单色及加权多色，N-BK7 平凸单透镜，矩形/环形瞳四种0.2 waves像差，以及明确列出的22种官方面型。面型参数作用、模式采用、保存重载和独立光学数值分别判断。

Ince 独立参考求解有限 Fourier 本征问题：`Y'' + ε sin(2η)Y' + (a − pε cos(2η))Y = 0`。有限模式为 `(p,m)=(0,0),(1,1),(2,0),(2,2),(4,0),(4,2),(4,4)`，有非零奇解的模式分别检查奇、偶分支；`w0=0.1 mm`、`f0=0.05/0.1 mm`，传播距离为0、0.5、1倍瑞利长度。相对复场只移除每个平面共同的一个复常数，空间相位、符号和强度分布保留。强度、相对复场及功率预算均为0.005，不推广到清单外阶次。

Cooke 的 FFT PSF 位于参考波长主光线的法平面，Huygens PSF 位于像面切平面；FFT MTF 的方向以物方/瞳坐标定义。非零视场下不能在未核对变换时把两种平面的频率轴直接等同。保存结果的 Fourier 和能量积分由 `scripts/diagnostics/validate_finite_imaging.py` 离线检查，不重新启动 Zemax。完整采样层、实际视场和波长必须匹配；采样加密与最终误差分别输出。

中心对称 Cooke 的 Y 视场、平直无倾斜像面采用 `f_beam,t = f_image,t / cos(theta)`，弧矢频率不变；theta 来自真实主光线和像面法线。多色结果使用实际主波长。该变换只调整 Fourier 参考频率，保留原生 PSF 与 MTF 数据。14°/20°、三个单色及加权多色共八组的 48 个最终 MTF 比较点最大误差为 0.00536，判据为 0.02。14°、644 nm 的 20 μm 包围能量在 512→1024 加密时仍超过 0.005 收敛判据，该条件暂缓，不能并入 MTF 通过结论。任意偏心或倾斜像面需要独立的二维坐标关系。

Chebyshev 的受控参考使用局部顶点补偿 `z = z_conic + sx*sy*(P(x/sx,y/sy)-P(0,0))`。常数项由输入系数在理论原点的取值决定，未从原生 Sag 拟合。归一化长度、2×2 阶活动系数的正负扰动、Sag、法线折射及保存重载具有依据；更高阶和其他 solve 组合按各自支持记录使用。

曲面/曲面热间隔先计算标称边缘间隔，再乘安装件的膨胀比例。若接触被镜片机械边缘限制，须加入安装件半径与实际接触半径间的 Sag 差修正，然后转回中心厚度。R50/−70 mm、机械半径3 mm、零 Chip Zone、安装 CTE0/50/100 ppm/°C、温度−20/19.99/20/20.01/60°C 的两个间隔，以及 Ry5°/Rx−3° 的全局变换分别核对；MCSD、SDIA、CHZN 明确热拾取。任意接触或热应力保持独立边界。

公差 Sampling=1 的独立 RMS 参考采用一个径向 Gaussian quadrature 节点 `r=sqrt(1/2)`、两个方位臂0/π。按保存样本的九个 XY 对称视场、视场权重、波长功率权重追迹，先计算各视场的多色质心与方差，再取视场加权方差均值的平方根。该数值与公差 RMS 准则比较，优化评价函数中的边界惩罚不参与计算。12×8 随机保存样本和8×7确定性样本共152项最大差为6.9e−16 mm；此依据限定 Sampling=1 及记录的补偿条件。

DetectorRectangle 的相干 Power 检查必须同时记录像素数、Polarization、NormalizeCoherentPower、分量通量及 Amplitude。既有8×8探测器的轴向正交模型和1×1探测器的局部分量矩阵分别列示，不能省略像素及归一化条件后合并结论。有限带宽模型的零距离源与探测器重合，没有有限传播命中；该点标记不适用，不能把零探测功率作为零光程相干度。

1×1受控模型采用0.25/0.75W、Jones夹角0/45/90°、入射倾斜0/2°、13个初相位，Polarization分别为0/1/2/3。其Power与 `Iinc_selected × |Σ sqrt(Pi) ci exp(iφi)|² / (Σ sqrt(Pi))²` 一致；ci为所选局部Jones分量，标志0时取1。分母来自全部入射光线，不能改为所选分量的振幅和。312点最大功率误差8.49×10⁻¹²W。24个零初相位检查中，API显示Amplitude的平方与Power一致，不能将这个显示量当作公式中的原始S_amp；该恒等关系只核对了这些零相位点。8×8既有模型使用独立记录的原生定义，不套用1×1显示量结论。详见相干汇总（历史参考）。

荧光宏通过 `ZRDPLAYBACK` 读取同一工作副本旁的 `rays.zrd`，以 `NSDP(1,3,0,1)` 读取 Polar 功率、`NSDP(1,3,-3,1)` 读取命中数。原生宏的总功率不提供逐段筛选数据；目标区间漏选时仍标记为数值失败。宏请求与结果（历史参考）保留完整波段、目标波段及无匹配区间。
