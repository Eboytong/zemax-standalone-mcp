# 成像与材料

成像能力包括几何图像、FFT 图像、线扩散/边缘扩散、扩展源图像、包围能量、几何位图、偏振与镀膜性能分析。

材料能力包括材料目录发现、折射率与热属性读取、内部透过率、色散曲线、玻璃图和无热玻璃图。

图像网格可按区域分页读取，并通过 `export_analysis_image` 导出。
