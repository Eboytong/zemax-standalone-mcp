# 非序列系统

非序列工具用于创建和编辑对象、切换混合或纯 NSC 模式、执行非序列追迹、读取探测器、保存或回放 ZRD，并读取光线段与对象几何。

支持光源光谱、方向性、照明结果和路径数据。对象与探测器数据支持分页读取。
