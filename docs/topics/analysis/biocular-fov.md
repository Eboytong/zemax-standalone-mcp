# 双目FOV

{"request":{"kind":"biocular_field_of_view","configurations":[1,0,2],"wavelength":1,"use_angles":true,"left":-14,"right":14,"bottom":-9,"top":9,"x_points":13,"y_points":9,"refinement_steps":8}}

默认配置[1]、波长1、角度模式、X/Y均−10至10、41×41初始网格、细化12步。最多四个配置槽，0禁用；编号从1开始。窗口严格递增，角度在(−90,90)内；余弦模式所有角点满足X²+Y²<1。每轴2–257点，初始总网格最多100000点，累计采样上限250000条。

本机原生专题是AS_Default，已检查的曲线/网格/RGB/散点/RGB散点/光线数据均为空，文本false。替代路径在独立配置副本中，从局部STOP中心(0,0,0)发射真实直接光线至像面；STOP前的曲面按正式定义忽略。副本配置写入后回读。STOP之后显式孔径按原生追迹，使用半口径时要求固定或Variable模式，自动半口径返回具体条件错误。

grids按values[y][x]返回初始通光状态0/1；rows分页保留配置、采样坐标、角色和原始光线状态/错误编号。series和contours返回细化边界及闭合状态、配置和scan_limited。初始网格每条通过/失败转换边二分细化；四边交叉单元用实际中心光线决定连接。扫描框内通光段作为scan_border补闭合，区分实际口径边界与扫描范围。孔洞和分离区域分别保留为轮廓。采样网格以下尺度的特征通过增加初始点数处理。
