# 光学分析

`run_analysis` 提供光斑、MTF、PSF、RMS、波前、Zernike、Seidel、畸变、场曲、相对照度、渐晕、Foucault、YNI、光线图和文本报告等分析。

分析结果以 `series`、`grids`、`rows` 或原生文本返回。使用 `get_task_result` 分页读取大结果，使用 `export_analysis_image` 导出图像。

工具参数、单位和可选设置见 [请求 schema](../../reference/tool-schemas.json)。
