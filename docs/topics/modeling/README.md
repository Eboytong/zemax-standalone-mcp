# 顺序系统建模

建模工具用于读取和修改系统设置、波长、视场、曲面、孔径、材料、坐标断点、镀膜、拾取和求解关系。

支持多重结构、变量、评价函数、镜头目录、设计工具与优化向导。写入操作返回实际采用值、模型修订和检查点信息。
