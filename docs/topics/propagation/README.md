# 物理光学传播

`run_pop` 执行 Physical Optics Propagation，返回采样、窗口、光束、模式与结果网格。`run_pop_convergence` 比较多组采样和窗口组合。

相关工具支持 Gaussian Beam、ZBF 复场文件、光纤耦合、屈光力分布图和 Universal Plot。
