# 并行任务阶段回报模板

任务编号、Agent、个人分支/工作区、共同起点标识、源码版本、Python环境：

本次阶段：计划与接口 / 实现与普通检查 / 原生证据与收口。

## 1. 本次实施计划

逐项列出功能编号及声明范围、现有缺口、正式接口/定义依据、要区分的假设、预期输入/输出、参考/容差、定向测试和完成条件。

## 2. 实际工作及代码

列出修改文件、类/函数/注册项、原因和消费者。共享入口补丁单列；说明请求、字段单位、设置写入/回读、有效结果和关闭路径。文档和schema提交具体建议修改。

## 3. 执行证据

| 功能编号 | 输入及来源 | 请求/实际设置 | 命令及原始输出 | 参考/容差 | 实际误差/输出 | 任务终态/关闭 | 模型恢复/重载 | 剩余条件 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 待填写 | | | | | | | | |

普通测试、原生测试及适用历史证据分别列出。写明实际passed/failed/skipped/xfail，数值诊断的内部结论单列。尚未运行的命令标“待执行”，并给出原生作业申请。

原生申请包含：功能编号、工作区/源码基线、Python环境、精确命令、模型和资源、预期时长、独立输出目录及成功/失败关闭预期。

## 4. 状态建议与下一步

逐项建议`in_progress/implemented/blocked/done`，附依据。遇到阻塞，列出已做探查、原始失败、缺少的许可/资源/接口及解除条件。重复台账/别名列为同步对象，新增完成计数由审查负责人决定。

列出需要审查的合同/参考变更、共享补丁依赖，以及下一条具体动作。
