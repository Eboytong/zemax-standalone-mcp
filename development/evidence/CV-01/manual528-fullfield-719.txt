Discussion The "Full Field" spot diagram type is similar to the "Standard" type, except all of the spots are plotted
with respect to the same reference point, as opposed to a separate reference point for each field position. This
provides some idea of how the spot would look relative to the other field points. For example, this can be used to
determine if two closely spaced image points can be resolved. The "Full Field" spot diagram type is less useful if the
spot radius is small compared to the total field size, because in this case the spots for each field will appear very
small compared to the distance between the spots. To increase the detail of the spots, enter a factor for the
Exaggerate setting.
