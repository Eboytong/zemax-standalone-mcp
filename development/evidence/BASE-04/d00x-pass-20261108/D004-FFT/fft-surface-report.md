## 4. 509 实际复算（由 ray 重建 pupil）

### 4.1 重建与验证
- 用 `iy,ix` 落格、`sqrt(intensity)·exp(2πi·OPD)` 建 256×256 复瞳（intensity 恒 1）；
- `pupil_autocorrelation`（2× 零填充）；DC=1.0000000000000002；
- 重建 `pupil_power` = **50613.0**（与存档 `pupil_power` 50613.0 一致）；支持单元 50613；
- 按存留 **3 种 `frequency_spacing`** 把 10 个原生网格节点频点映射到 acf lag、双线性采样；
- **复现校验**：3 种 spacing 下 10 点 recomputed reference 与 stored reference **逐点吻合**（`all_points_match_stored=True`），recomputed max error 与 stored max error 相等。

### 4.4 可支持的结论（不越界）
- **幅度**：本数据集 intensity 恒 1.0 → 幅度加权退化；**幅度归一化不能解释**该误差（但此数据也无法检验非均匀空间幅度）。
- **支持域**：全部 ray `error_code=0`、`vignette=0`（无光线丢失）；但这**不排除投影后的支持域/掩膜差异**。
- **集中方向**：误差沿 fx 小（≤0.0025）、沿 fy 大（0.08–0.17，max 0.16546@fy=49.27）；且三种 spacing 下 recomputed 与 stored 一致 → 该差异是"原生 cross-outlet MTF"与"由 ray 重建的复瞳自相关"之间的真实差异，**呈强各向异性**。
- **严格边界**：沿 fy 误差大**只支持"各向异性（椭圆）投影"假设**，**不能断言已定位根因、也不能断言残差为固有**。
- **缺口（正式定义层面）**：**正式物理映射/参考球与投影定义未建立**（光线瞳坐标/像面 position → 原生相干-OTF 椭圆瞳频率节点的参考球、投影面与各向异性标定未定义）；据此保留原误差、不虚构重映射。
